# Quick Start Guide

Get ContentMind up and running in 5 minutes!

## Step 1: Get an API Key (2 minutes)

### Using OpenAI (Recommended)
1. Go to https://platform.openai.com/api-keys
2. Sign up (they give free credits!)
3. Click "Create new secret key"
4. Copy the key (starts with `sk-`)

### Using Anthropic Claude
1. Go to https://console.anthropic.com/
2. Sign up
3. Get your API key from the dashboard

## Step 2: Install Extension (1 minute)

1. Open Chrome and go to `chrome://extensions/`
2. Turn on "Developer mode" (top-right toggle)
3. Click "Load unpacked"
4. Select the `contentmind-extension` folder
5. Done! Icon appears in toolbar

## Step 3: Configure (1 minute)

1. Click the ContentMind icon in your browser
2. Click the ⚙️ settings icon
3. Paste your API key
4. Select your provider (OpenAI or Anthropic)
5. Add your interests (e.g., "web development, AI, productivity")
6. Click "Save Settings"

## Step 4: Try It Out! (1 minute)

1. Go to any YouTube video (e.g., https://youtube.com)
2. Click the ContentMind icon
3. Click "Generate Summary"
4. Wait a few seconds... tada! 🎉

## That's It!

Now explore:
- **Mindmap tab**: Visualize the content structure
- **Chat tab**: Ask questions about the video
- **Relevance tab**: See how relevant it is to you

## Pro Tips

- YouTube videos with captions work best
- Educational content produces richer summaries
- Update your interests in settings for better personalization
- Try both AI providers to see which you prefer
