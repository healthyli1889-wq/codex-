# Icon Instructions

The extension currently uses SVG placeholders for icons. For production, you should replace these with proper PNG icons:

## Required Icon Sizes
- `icon16.png` - 16x16 pixels (toolbar)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## How to Create Icons

1. **Design your icon** (recommended size: 512x512px)
2. **Export to PNG** at the required sizes
3. **Replace the SVG files** with PNG versions:
   - `assets/icon16.png`
   - `assets/icon48.png`
   - `assets/icon128.png`

## Design Guidelines
- Use simple, recognizable shapes
- Ensure good contrast for visibility
- Test on both light and dark backgrounds
- Follow browser extension icon guidelines
